# FileDock

FileDock is a file management and storage application built with Express and Prisma. It allows users to upload, organize, view, and download their files through a folder-based storage system.

This project is based on the [File Uploader project](https://www.theodinproject.com/lessons/nodejs-file-uploader) from The Odin Project's Node.js curriculum.

## Planned Features

* User authentication with Passport.js
* Persistent user sessions
* File uploads
* Create, view, edit, and delete folders
* Organize uploaded files into folders
* View file information such as name, size, and upload date
* Download uploaded files
* Cloud-based file storage
* File type and size validation
* Shareable folder links with configurable expiration *(extra credit)*

## Tech Stack

* Node.js
* Express.js
* PostgreSQL
* Prisma ORM
* Passport.js
* Multer

Cloud storage will be integrated later in development.
